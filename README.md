# AI Workplace Productivity Assistant

AI-powered workspace built for the CAPACITI AI Skills Acceleration Programme.

## What It Does
Five specialized assistants to help you write, plan, research, and communicate — all in one clean workspace.

### 1. Smart Email Generator
Draft polished emails in seconds with the right tone.

### 2. Meeting Notes Summarizer  
Turn raw transcripts into action-ready summaries.

### 3. AI Task Planner
Break goals into prioritized, scheduled tasks.

### 4. AI Research Assistant
Get structured briefings on any topic.

### 5. AI Chatbot
Ask anything and get fast, helpful answers.

## Important Note
All outputs are AI-generated drafts. Review and edit before use. Do not add false information.
